# Plataforma Web para la Gestión de Comunidades ESPOL — Frontend

Frontend en **JavaScript + React + Vite**, adaptado al diseño visual de Figma.

## Importante

Se eliminó por completo la sección **"Acceso rápido (demostración)"** y se reemplazaron los datos simulados principales por llamadas reales a la API REST interna de Laravel.

## Tecnologías

- JavaScript
- React
- Vite
- Tailwind CSS
- Laravel REST API como backend

## Ejecutar

1. Copiar `.env.example` como `.env`.
2. Verificar que Laravel esté ejecutándose en `http://127.0.0.1:8000`.
3. Ejecutar `npm install`.
4. Ejecutar `npm run dev`.
5. Abrir `http://127.0.0.1:5173`.
